# Project Map

Короткая карта проекта для человека, который впервые открыл репозиторий.

## 1. Главная идея

Приложение собирает данные из DBF/XLSX-источников и выпускает Excel-отчёты в нескольких бизнес-режимах. GUI и CLI здесь тонкие: основная полезная логика живёт в `src/modes/*`.

## 2. Входные точки

- [`src/main.rs`](src/main.rs) — desktop GUI на `eframe/egui`.
- [`src/bin/batch_run.rs`](src/bin/batch_run.rs) — headless-запуск модулей без GUI. Удобен для smoke-тестов и для понимания того, какие `Request` ждёт каждый модуль.

## 3. Слои

Зависимости идут строго в одну сторону: `ui` и `cli` знают про `modes`, `modes` про них — нет. Проверяется глазами по `use crate::`, нарушение сразу заметно.

```
main.rs / bin/batch_run.rs
        ↓
   cli.rs ─→ ui/            ← интерфейс: окно, вкладки, тема
        ↓        ↓
      modes/     ↓          ← бизнес-логика отчётов
        ↓        ↓
  paths/  tabular/  domain/ ← пути, чтение таблиц, справочник месторождений
```

| каталог | что внутри |
|---|---|
| [`src/lib.rs`](src/lib.rs) | оглавление крейта |
| [`src/cli.rs`](src/cli.rs) | параметры запуска, выбор начального экрана |
| [`src/domain.rs`](src/domain.rs) | `Mest` — коды месторождений и подписи, общие для интерфейса и модулей |
| [`src/paths/`](src/paths) | поиск входных файлов и каталогов вывода |
| [`src/tabular/`](src/tabular) |низкоуровневое чтение DBF/XLSX, кэш источников, разбор чисел |
| [`src/modes/`](src/modes) | по одному подкаталогу на отчёт |
| [`src/ui/`](src/ui) | оболочка, вкладки, компоненты, тема |

## 4. Режимы

Семь кнопок интерфейса — шесть модулей плюс «Все и сразу», который запускает остальные.

| кнопка | модуль | источники |
|---|---|---|
| Все и сразу | — (оркестрация в [`ui/screens/batch.rs`](src/ui/screens/batch.rs)) | — |
| ГДИ | [`modes/gdi/`](src/modes/gdi) | DBF; ветка Excel/KOTS в `gdi/kots/`, общий расчёт лимитов в `gdi/limits.rs` |
| Статика | [`modes/ppl/`](src/modes/ppl) | `plast.dbf`, `СкважиныГДН.xlsx` |
| Сводка | [`modes/ss/`](src/modes/ss) | `eer1.dbf`, `СкважиныГДН.xlsx` |
| Ведомость | [`modes/ved/`](src/modes/ved) | результаты Статики и Сводки, шаблоны Excel |
| Телеметрия | [`modes/telemetry/`](src/modes/telemetry) | телеметрические выгрузки |
| из ГДМ | [`modes/gdm/`](src/modes/gdm) | CSV тНавигатора из `~/tNavigator_scripts/GDM/` и справочник скважин |

## 5. Устройство модуля

Внутри режима принят разбор на `mod.rs` (вход и оркестрация), `data.rs` (модели и преобразования), `source.rs` (чтение), `writer.rs` (сборка книги).

**Правило размера: файл делим, когда он перевалил за ~400 строк, а не заранее.** Пустая `data.rs` на двадцать строк вредит не меньше, чем файл на полторы тысячи: и в том, и в другом случае по имени нельзя предсказать, где логика. Поэтому `telemetry` живёт одним файлом, а у `gdm` и `ved` разбор полный.

Публичный контракт у всех одинаковый: `Request` + `execute(&Request) -> Result<Vec<PathBuf>>`.

## 6. Типовой жизненный цикл запроса

1. Пользователь выбирает параметры на вкладке или передаёт их через `batch_run`.
2. Собирается `Request` конкретного модуля.
3. `paths/` разрешает реальные входные файлы.
4. Модуль читает DBF/XLSX и строит внутренние строки и агрегаты.
5. Модуль генерирует итоговый `.xlsx`.
6. GUI или CLI показывает итоговые пути и ошибки.

## 7. Где безопаснее вносить изменения

| задача | куда смотреть |
|---|---|
| новый флажок в форме | `src/ui/screens/<вкладка>.rs` |
| подвинуть элемент интерфейса | [`src/ui/screens/layout.rs`](src/ui/screens/layout.rs) |
| новый источник или каталог | [`src/paths/`](src/paths) |
| формат итогового файла | `writer.rs` нужного режима |
| новое месторождение | [`src/domain.rs`](src/domain.rs), затем `paths/` и `modes/` |

## 8. На что обратить внимание

- Тяжёлая работа в GUI вынесена в фоновые потоки, паника в них перехватывается и показывается в интерфейсе — поэтому `panic = "abort"` в профиле включать нельзя.
- В `vendor/rust_xlsxwriter/` лежит форк библиотеки записи xlsx, подключённый через `[patch.crates-io]`. Что и зачем изменено — в [`vendor/rust_xlsxwriter/ФОРК.md`](vendor/rust_xlsxwriter/ФОРК.md).
- Самые большие файлы: [`tabular/report_xlsx.rs`](src/tabular/report_xlsx.rs), [`modes/ved/writer.rs`](src/modes/ved/writer.rs), [`modes/gdm/data.rs`](src/modes/gdm/data.rs), [`ui/app.rs`](src/ui/app.rs) — читать по секциям сверху вниз.
